# Les poèmes de Christian Lambillotte

A collection of poems by Christian Lambillotte (1957–2026), a Belgian poet from Ghent who wrote in French, Dutch, and Italian.

This repository hosts the source code for his poetry website, built as a static site on GitHub Pages.

## 🌐 Visit the website

**[www.christianlambillotte.be](https://www.christianlambillotte.be)**

## About the poems

The collection explores themes of life, humanity, family, and existential reflection — from a grandfather's letter to his granddaughter, to a dialogue between a foetus and a skeleton, to a playful ode to the potato.

Poems are presented in an interactive reading experience with fullscreen viewing, smooth transitions, and support for both light and dark modes.

## Languages

- 🇫🇷 French
- 🇳🇱 Dutch
- 🇮🇹 Italian
